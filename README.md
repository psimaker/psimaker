## Projects

### 🍎 Apps I ship

- 📝 **[VaultSync](https://github.com/psimaker/vaultsync)** — self-hosted Obsidian sync for iPhone & iPad. Swift 6 + SwiftUI, with Syncthing embedded via Go/gomobile and an optional push relay. Localized in EN/DE/ES/中文. On the App Store. <br>[![Stars](https://img.shields.io/github/stars/psimaker/vaultsync?style=flat-square&logo=github&color=2AB5B3&label=stars)](https://github.com/psimaker/vaultsync/stargazers)
- 📊 **[Claude Usage Menu](https://github.com/psimaker/claude-usage-menu)** — macOS menu-bar app showing your real-time Claude.ai usage (5h session, weekly, Sonnet). Reads Claude Code's token from the Keychain; ships as a signed, notarized release.

### 🔒 Privacy on the open web

- 🔎 **[LOOGI](https://github.com/psimaker/loogi)** — privacy-first metasearch on SearXNG, with a hardcoded theme, a curated engine list, and config baked into the image at build time. 16 ADRs explain every non-trivial call. Live at [loogi.ch](https://loogi.ch).
- 🕵️ **[Twitter/X Spy Link Remover](https://github.com/psimaker/twitter-x-spy-link-remover)** — kills `t.co` tracking redirects so your clicks go straight to the real URL. Pure vanilla JS, no backend, no requests. [On Greasy Fork.](https://greasyfork.org/scripts/568483-twitter-x-spy-link-remover)

### ⚙️ Infrastructure & automation

- 🏠 **[homelab](https://github.com/psimaker/homelab)** — my entire self-hosted stack as code: **17 services on one bare-metal box** ("airbase", Debian), all Docker Compose. Defense-in-depth networking where the bind address itself is a security layer, VPN-gated egress, automatic updates, and a Telegram ping for every event that matters. Published as a reference, with secrets stripped out. Hosts [loogi.ch](https://loogi.ch) in production.

## What I'm into

- **Automating everything I touch** — auto-updating containers, config-as-code, signed-release pipelines, a Telegram ping for every event that matters. If I do it twice, I script it.
- **Owning my data** — self-hosted notes, photos, passwords, media, and search. The cloud is someone else's computer; mine lives in a Lian-Li case in Switzerland.
- **Going agentic** — building toward AI agents that do real work, and native tools that put the models right where I'm working.
- **Digitalizing the analog** — turning manual, cloud-locked workflows into self-owned, automated ones.
